## 1. 复现命令

```bash
cd TcoderMonitor && ./scripts/build_app.sh release \
  && ./scripts/capture_pages_isolated.sh /tmp/tcoder-pages-$(git rev-parse --short HEAD)
```

`scripts/capture_pages_isolated.sh` 会把取证实例的支持目录指到 `/tmp` 下的沙箱
（`ProjectStore.resolveStorageDirectory` 认 `TCODER_SUPPORT_DIR`，只接受绝对路径），
所以它**不需要你先退出别的 App 实例**，也不会碰你 `~/Library/Application Support` 里的项目列表。
脚本开头还会跑 `verify_provenance.sh`：dist 与当前源码不一致就**拒拍**。

## 4. 这份表什么时候会再次过期

任何改动评分口径、分母定义或页面读数的合并，都会让 §2 的数字失效。
判据不是"我改了什么"，而是**重跑一次 §1 的命令，看两表是否逐格一致**。
取证脚本产出的九张图与沙箱里那份 `reports/*.json` 都保留在 `/tmp`，
可以逐格回读——**别把本文件当成不需要重跑就能更新的说明书**。
