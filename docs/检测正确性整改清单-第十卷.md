## 这一批把 #53 的两个候选解释**干净地分开了**

## 新尺第一次跑，抓到的是我自己写的夹具

**`"w"` 那个句柄在实参求值之前就把文件截成 0 字节**，于是夹具变成空文件，而尺子回的是：

## 可迁移的一条

**"rc=0" 不等于"量到了"**，尤其当尺子有一条宽容分支叫「记未覆盖」的时候 ——
"未覆盖"是一个能吞掉任何东西的黑洞分类。⇒ 凡尺子有"未覆盖"这一档，就必须同时有
**"未覆盖的东西不许超过 X / 不许是全部"** 那样的分母断言，否则它就是 §152 那次
「数了几批由临时 glob 答」的文档版。这次我的分母断言是被自己的假夹具逼出来的，不是设计出来的 ——
所以顺序对了：先写反例，反例把它照出来。
