## §217 #123：判据① 的 p95 判定落到批次产物里——稀缺的真人窗口不能只剩一次 stdout 的尾巴

**为什么这条排在请需求方滚动之前**：判据①（交互期 hitch 帧＝0 且 p95 帧间隔 ≤8.4 ms）唯一的合法取证出口是
**真人滚 3×30 秒**（AGENTS §2.2 禁一切点击/滚动自动化，`INPUT=synth` 也在令内）。而节拍那把尺的判定此前只住在
`perf_report.sh` 的一行里：`python3 perf_cadence.py … 2>&1 | tail -7 | sed … || true`——
**判定没有持久读者**（第 46 类那一族），`tail -7` 还可能把判定行自己截掉，`|| true` 又把"判不成"与"判了未达标"压成同一件事。
⇒ 那种窗口拍完若只剩一次 stdout，就等于没量过。所以先修这一条，再去要那 30 秒。

**做法（一个出口、两处调用）**：新增 `land_cadence_verdict <outdir>`（住 `perf_measure_io.sh`——录制侧与重打侧都要用同一个出口，
两处各写一份必然分叉）：全文落 `cadence.txt`、判定行落 `cadence-verdict.txt`，**缺 `hitches-renders.xml` 也要写一句「未采到」**
⇒ 三态齐（达标／未达标／未采到）。`perf_cadence.py` 加 `--verdict-out`，取行按话术标记而非行号（行号会随脉冲有无漂移）；
`cmd_idle` 在导表之后立刻调它（不等谁重打 report），`cmd_report` 改走同一个函数。report 档的退出码一字未改（它自己注释里写明合判是给人读的）。
**现量**：拿 `cert17-idle-run1` 真产物走一次新出口 ⇒ `cadence-verdict.txt` 印
「权威 hitch 数 0 个 ⇒ 0.00 /s ／ 按名义(120Hz)预算 8.417 ms：p95 **未达标**（超 0.070 ms） ／ 按实测周期预算 8.496 ms：p95 达标 ／ 退出码 1」。

**常驻臂＝selfcheck 第 88 项**：两腿。python 腿造三份夹具（精确 8.3333 ms 步进 ⇒ 两把预算都过；8.5 ms ⇒ 名义不过、实测过；）
断言**落盘文件里**有对应判定且带退出码；bash 腿喂一个没有 `hitches-renders.xml` 的目录 ⇒ 必须写出「未采到」。
⚠ 断言一律查文件不查 stdout——`tail -7` 正是这次的缺陷本体。夹具形状照第 35 项那份（生产解析器按 `id` 建表回查，
没有全局唯一 id 会静默解析成 0 帧 ⇒ 臂会去抓一个真件里不存在的形状）。

## §218 #62：认证只能绑在冻结的产品码上——这条不该靠人记，写成一张调度约定（并把已有的机器读者点清）

**问题形状**（09-26 晚实测）：`T2 认证成立` 这句话里的"成立"绑的是**一份产物**，而队列活跃期一晚上换了 6 次产品码
⇒ "T2 = 交付头"在数学上不可能同时为真；任何人在下一笔引用那句认证时，都可能把它挂在一枚已被超掉的二进制上。

**已经有的机器读者（先把这些点清，别再造第二把）**：
① 每趟 `meta.json` 里两格——`measured_rev`（这枚二进制是谁，走唯一装配口 `provenance_target_rev`）
与 `main_product_drift`（落后 main 几笔**产品码**，走 `provenance_main_drift`，"取不到"不等于 0）；
② 收口尺 `verify_provenance.sh`（rc=1→0 才算同源）；③ 身份比的是**产物码 tree**而不是 commit sha（#14）。
⇒ 所以缺的**不是判据，是引用时的动作**：把"引用一句认证之前先比一次 tree"变成约定，而不是指望别人记得。

**约定（本轮起我自己先守，并写在这里供各流引用）**：
1. **认证句必须点名一棵 `Sources` tree**（`git rev-parse <头>:TcoderMonitor/Sources`），不许只写"某提交/交付头上成立"；
   本次实例：② 的认证句现在长这样——「在 `Sources` tree `8bc57fc72716…`（＝main `b72ae4a` 的产物码）上成立」。
2. **稀缺取证（真人窗口、认证批）之前先请求 Sources 冻结窗**：那一窗内只合 docs/scripts/Tests；
   有人要落上屏码就先排队，等取证完再合（这条比"事后发现被超掉再重认证"便宜一个数量级）。
3. **换码即失效，且不许静默继承**：产品码一变，引用旧认证的那一行要么重跑一窗、要么显式标"旧产物读数"。
   `#126` 就是按这条排的——它会改 `ProcessInspector` 热循环 ⇒ 故意压在真人窗口之后。
4. 每次收场把 `main_product_drift` 与产物码 tree 现读一遍再写台账（本轮现量：`8bc57fc72716…` 自 09-25 18:33 未变，
   期间漂移全是 docs/scripts/Tests ⇒ `cert17` 那枚② 认证至今指同一份产物）。
