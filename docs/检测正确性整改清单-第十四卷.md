## §217 #123：判据① 的 p95 判定落到批次产物里——稀缺的真人窗口不能只剩一次 stdout 的尾巴

**为什么这条排在请需求方滚动之前**：判据①（交互期 hitch 帧＝0 且 p95 帧间隔 ≤8.4 ms）唯一的合法取证出口是
**真人滚 3×30 秒**（AGENTS §2.2 禁一切点击/滚动自动化，`INPUT=synth` 也在令内）。而节拍那把尺的判定此前只住在
`perf_report.sh` 的一行里：`python3 perf_cadence.py … 2>&1 | tail -7 | sed … || true`——
**判定没有持久读者**（第 46 类那一族），`tail -7` 还可能把判定行自己截掉，`|| true` 又把"判不成"与"判了未达标"压成同一件事。
⇒ 那种窗口拍完若只剩一次 stdout，就等于没量过。所以先修这一条，再去要那 30 秒。

**做法（一个出口、两处调用）**：新增 `land_cadence_verdict <outdir>`（住 `perf_measure_io.sh`——录制侧与重打侧都要用同一个出口，
两处各写一份必然分叉）：全文落 `cadence.txt`、判定行落 `cadence-verdict.txt`，**缺 `hitches-renders.xml` 也要写一句「未采到」**
⇒ 三态齐（达标／未达标／未采到）。`perf_cadence.py` 加 `--verdict-out`，取行按话术标记而非行号（行号会随脉冲有无漂移）；
`cmd_idle` 在导表之后立刻调它（不等谁重打 report），`cmd_report` 改走同一个函数。report 档的退出码一字未改（它自己注释里写明合判是给人读的）。
**现量**：拿 `cert17-idle-run1` 真产物走一次新出口 ⇒ `cadence-verdict.txt` 印
「权威 hitch 数 0 个 ⇒ 0.00 /s ／ 按名义(120Hz)预算 8.417 ms：p95 **未达标**（超 0.070 ms） ／ 按实测周期预算 8.496 ms：p95 达标 ／ 退出码 1」。

**常驻臂＝selfcheck 第 88 项**：两腿。python 腿造三份夹具（精确 8.3333 ms 步进 ⇒ 两把预算都过；8.5 ms ⇒ 名义不过、实测过；）

⚠ 断言一律查文件不查 stdout——`tail -7` 正是这次的缺陷本体。夹具形状照第 35 项那份（生产解析器按 `id` 建表回查，

## §218 #62：认证只能绑在冻结的产品码上——这条不该靠人记，写成一张调度约定（并把已有的机器读者点清）

**问题形状**（09-26 晚实测）：`T2 认证成立` 这句话里的"成立"绑的是**一份产物**，而队列活跃期一晚上换了 6 次产品码
⇒ "T2 = 交付头"在数学上不可能同时为真；任何人在下一笔引用那句认证时，都可能把它挂在一枚已被超掉的二进制上。

**已经有的机器读者（先把这些点清，别再造第二把）**：
① 每趟 `meta.json` 里两格——`measured_rev`（这枚二进制是谁，走唯一装配口 `provenance_target_rev`）
与 `main_product_drift`（落后 main 几笔**产品码**，走 `provenance_main_drift`，"取不到"不等于 0）；
② 收口尺 `verify_provenance.sh`（rc=1→0 才算同源）；③ 身份比的是**产物码 tree**而不是 commit sha（#14）。
⇒ 所以缺的**不是判据，是引用时的动作**：把"引用一句认证之前先比一次 tree"变成约定，而不是指望别人记得。

**约定（本轮起我自己先守，并写在这里供各流引用）**：
1. **认证句必须点名一棵 `Sources` tree**（`git rev-parse <头>:TcoderMonitor/Sources`），不许只写"某提交/交付头上成立"；
   本次实例：② 的认证句现在长这样——「在 `Sources` tree `8bc57fc72716…`（＝main `b72ae4a` 的产物码）上成立」。
2. **稀缺取证（真人窗口、认证批）之前先请求 Sources 冻结窗**：那一窗内只合 docs/scripts/Tests；
   有人要落上屏码就先排队，等取证完再合（这条比"事后发现被超掉再重认证"便宜一个数量级）。
3. **换码即失效，且不许静默继承**：产品码一变，引用旧认证的那一行要么重跑一窗、要么显式标"旧产物读数"。
   `#126` 就是按这条排的——它会改 `ProcessInspector` 热循环 ⇒ 故意压在真人窗口之后。
4. 每次收场把 `main_product_drift` 与产物码 tree 现读一遍再写台账（本轮现量：`8bc57fc72716…` 自 09-25 18:33 未变，

## §220 #127：收尾人手复核「没做成」被读成「做成且没人动」——未判这一格第一次落盘，并由唯一那把资格尺读回

**形状**（不是推理，是 09-27 实测复现）：`post_window_quiescence` 在静默探针取不到时只印一行
「（收尾静默探针取不到，污染判定不做）」就 `return 0`，**meta 一个字段都不落**；而唯一的资格判据
`period_eligibility` 的形状是「没有污染标记就算合格」。于是尺子掉下来的那一趟**必然放行**：

```
===== period=interaction：跑收尾复核（探针取不到）=====
    （收尾静默探针取不到，污染判定不做）
  meta 里的收尾相关字段： （一个都没有）
  period_eligibility → eligible=True | 有资格答 T1（交互期 hitch = 0）
===== period=idle：同上 =====
  period_eligibility → eligible=True | 只答心跳期；**不许**拿去交 T1
```

两句都是绿灯，而**同一句还被 `perf_trio_agreement` 读进 §1.3 的 3/3 计数**（一把判据、两个读者，
所以这一处修完 ① 与 ② 一起受益）。危害不是假想：判据① 唯一的取证出口是一次稀缺的真人窗口
（AGENTS §2.2 禁一切点击/滚动自动化），那一趟若正好撞上尺子掉，就会**在没有一次人手证据的情况下
把「交互期 hitch=0」交出去**。而「探针时好时坏地报 -1.00」是记过账的真实故障形状——
它编译到 `$SCRATCH` 下的哈希名，别的会话在同名位置放个目录就编译失败（`perf_probes.sh` 头注 ①②）。

**先量危害半径，再动判据**（避免把历史读数顺手改口）：盘上 245 批里 63 批没有 `quiescence_after_seconds`，
但**其中 0 批是「已完成导表却被放行」的**——今天 cert13／cert14probe／cert15／cert16 那几批缺这一格，
是因为它们带着 `REFUSED`（录制开始前就被闸门拒掉，压根没走到收尾复核）。
⇒ 这是一条**潜伏的、单向朝好看错**的通道，不是一次已经发生的错账。这句话必须这样写，不许写成"已避免了几批"。

**修法（写侧落格、读侧负责拒，只加字段不加闸门）**：
1. `post_window_quiescence`：取不到 ⇒ `meta_write ... quiescence_recheck=unavailable`（并照旧 `return 0`、
   样本照旧留盘——拒发生在**引用那一刻**，不在录制中途灭失一趟）；做成 ⇒ `quiescence_recheck=measured`。
   正对照那一格不是装饰：没有它，「没写成 unavailable」与「这段代码根本没跑」在下游长得一模一样。
2. `perf_eligibility.human_recheck_refusal`：显式 `unavailable` ⇒ 两档都拒，拒因写「没做成／既没证有人在动
   也没证没人动」。单独一枚函数而不是往 `period_eligibility` 里塞——那枚函数已经 47 行，再长就撞
   「函数 ≤ 50 行」那把门（本仓口径：拆一格一个函数才是修复，抬线不算）。
3. **裁定：缺这一格的老批次不追溯**。`period_eligibility` 只认显式 `unavailable`。
   把「缺字段」一律判死会顺手改动 63 批历史读数（含 switch 档那几批本来就没有 `period` 的形状），
   而那要另开一次裁定、不该藏在一个修 bug 的 diff 里——第 7 格断言就是把这条裁定钉住的哨兵。

**常驻臂＝selfcheck 第 71 项（`selfcheck_quiescence_recheck_states`，88→89 项，0 失败）**，两腿：
python 腿七格 `1|0|0|1|0|0|1`（有人在动→放行／未判两档都拒／没人动→放行／污染→拒／声明交互却没人→拒／缺格不追溯→放行）
＋话术钉「没做成」三个字必须在拒因里；bash 腿**真跑写侧再让读侧判**（四行夹具落在本轮 outdir 的
`quiescence-recheck/` 下，避开批次普查分母），输出 `idle|measured|Y idle|unavailable|N interaction|measured|Y interaction|unavailable|N`。

**两格反向都有牙（当场破坏再复原）**：
- 破坏写侧（不落那一格）⇒ 臂红，且打印的正是旧形状：`interaction|(absent)|Y`——**未判又被放行**；
- 破坏读侧（`human_recheck_refusal` 恒空）⇒ 臂红在七格那行（拿到 `1|1|1|1|0|0|1`）；
