### 4.1 分带读数怎么读（我自己差点读错过一次）

批次 ABC 合入后九页复拍：**六页纯白 89–97%**，但「贡献者 36.2% / 复杂度风险 35.5%」
仍落在灰带里。先看数就下结论会误判 —— 灰带这一档是 min 通道 **235–249**，
而井色 `#F5F5F7` 的 min 是 245，**它天生就在灰带里**，可它对纯白只有 1.09:1，肉眼近乎不可见。
所以这两个 35% 不等于"还有 35% 的脏"。真正的脏是上一版那种 `#EAEAEC`（min 234，
对纯白 1.19:1，且旧地面本身 241 → 灰压灰）。
**结论**：分带数只能用来盯"整页塌成一层灰"这种结构问题（旧版 87–95% 是铁证），
不能当"脏/干净"的评分。判干净仍然靠眼睛 + 源码事实（谁画了填充）。

### 6.6 深色分带读数的一个坑（写下来免得下轮误读）

`pixel_audit` 的"白/灰带"两档是按 **min 通道 ≥250 / 235–249** 分的，那是为浅色态设计的。
深色态地面是 `#000000`，于是九页全部报「白 0.0%」—— 这个 0 **不是**缺陷，是尺子只量了一侧。
深色态该看的是"地面桶占比"（报里 `地面=0@63%…98%`）与"有没有一层不透明的中灰糊住内容"。
下一轮把这两档按外观分别定义（浅色看白占比，深色看地面占比 + 井与地面的对比是否 > 1.15:1）。
